# アプリのアイコン

夕暮れの曲がり道と、G メーター(内側の円の中心で落ち着いた緑の点 = 酔いにくい、なめらかな運転)。

`DriveLogger/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon.png` は、画像生成 AI で作った絵を
1024×1024 の不透明な PNG にしたもの。`make_icon.py`(SVG で描く版)は、同じモチーフの下書きとして残してある。

差し替えるときは、1024×1024・透明な部分なしの PNG で上の AppIcon.png を置き換える。
角の丸めは iOS がするので、四角のままでよい。
